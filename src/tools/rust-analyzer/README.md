* rust-analyzer
  * == language server /
    * 's features
      * go-to-definition
      * find-all-references
      * refactorings
      * code completion
      * integrated formatting -- with -- rustfmt
      * integrated diagnostics -- with -- rustc & clippy
    * provides
      * IDE functionality -- for -- writing Rust programs
  * requirements to use it
    * ANY editor / that supports the [Language Server Protocol](https://microsoft.github.io/language-server-protocol/)
      * _Examples:_ VS Code, Vim, Emacs, Zed, ...
